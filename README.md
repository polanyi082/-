# 한성대학교 AI 바이브코딩 기초·심화 프로그램 안내 페이지

모집 포스터를 **웹페이지 형태로 공유**하기 위한 정적 사이트입니다.
`index.html` 단일 파일로 동작하며, 이미지·QR·로고는 모두 파일 안에
base64로 포함되어 있어 별도 리소스 없이 그대로 열립니다.

## 공개 주소 (GitHub Pages)

```
https://polanyi082.github.io/-/
```

### Pages 켜는 방법 (최초 1회)

1. 이 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
2. **Source** 를 `Deploy from a branch` 로 선택
3. **Branch** 를 `main` / 폴더는 `/ (root)` 로 지정 후 **Save**
4. 1~2분 뒤 위 주소로 접속하면 페이지가 뜹니다.

## "이미지처럼 보이던" 문제와 해결

원본 파일은 1000×1414px 고정 크기의 인쇄용 포스터 레이아웃이었습니다.
`<meta name="viewport">` 가 없어서 휴대폰에서 열면 브라우저가 데스크톱 폭
(980px)으로 렌더링한 뒤 통째로 축소해 버려, 글자를 읽을 수 없는
**한 장의 이미지처럼** 보였습니다.

공유용 웹페이지로 쓰기 위해 다음을 적용했습니다.

| 항목 | 내용 |
|---|---|
| 뷰포트 메타 | `width=device-width, initial-scale=1` 추가 — 모바일이 실제 화면 폭을 기준으로 렌더링 |
| 화면 폭별 동작 | 1000px↑ 원본 크기 / 860–1000px 비율 축소 / 860px↓ 세로 재배치 |
| 모바일 재배치 | 2단 강의 카드·CTA·푸터를 세로로 쌓고, 제목은 `clamp()` 로 가변 크기 적용 |
| 장식 요소 | 1000px 캔버스 좌표 기준인 `+`·원·SVG 일러스트는 좁은 화면에서 숨김 |
| 가로 스크롤 | 모든 폭(320px 포함)에서 가로 스크롤 0 |
| 링크 미리보기 | Open Graph / Twitter Card 메타 + `og-image.png` (1200×630) |
| 인쇄 | `@media print` 에서 축소를 해제해 원본 포스터 비율로 출력 |

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 안내 페이지 본문 (단일 파일) |
| `og-image.png` | 카카오톡·페이스북 등 링크 미리보기 카드 (1200×630) |
| `preview.png` | 포스터 전체 이미지 (1000×1414) |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 생략 |

## 내용 수정

`index.html` 을 열어 해당 텍스트를 고친 뒤 커밋하면 Pages에 자동 반영됩니다.
날짜·연락처·QR 등 자주 바뀌는 값은 `<div class="content">` 안에 모여 있습니다.
